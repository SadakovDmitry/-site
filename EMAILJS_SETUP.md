# Настройка формы обратной связи (EmailJS)

Форма обратной связи настроена для отправки писем на **info@fondcosmos.ru** через сервис EmailJS.

## Инструкция по настройке:

1. **Зарегистрируйтесь на EmailJS**
   - Перейдите на https://www.emailjs.com/
   - Создайте бесплатный аккаунт

2. **Создайте Email Service**
   - В панели управления перейдите в раздел "Email Services"
   - Добавьте новый сервис (Gmail, Outlook, или другой)
   - Следуйте инструкциям для подключения вашего email-провайдера
   - Скопируйте **Service ID**

3. **Создайте Email Template**
   - Перейдите в раздел "Email Templates"
   - Создайте новый шаблон
   - В поле "To Email" укажите: `info@fondcosmos.ru`
   - В поле "Subject" укажите, например: `Новое сообщение с сайта от {{from_name}}`
   - В теле письма используйте следующие переменные:
     ```
     Имя: {{from_name}}
     Организация: {{from_organization}}
     Контактные данные: {{from_contact}}

     Сообщение:
     {{message}}
     ```
   - В поле "Reply To" укажите: `{{reply_to}}`
   - Скопируйте **Template ID**

4. **Получите Public Key**
   - В разделе "Account" → "General" найдите **Public Key**
   - Скопируйте его

5. **Настройте переменные окружения**
   - Создайте файл `.env` в корне проекта (если его еще нет)
   - Добавьте следующие строки:
     ```
     REACT_APP_EMAILJS_SERVICE_ID=ваш_service_id
     REACT_APP_EMAILJS_TEMPLATE_ID=ваш_template_id
     REACT_APP_EMAILJS_PUBLIC_KEY=ваш_public_key
     ```
   - Замените значения на ваши реальные ID и ключ

6. **Перезапустите приложение**
   - Остановите сервер разработки (если запущен)
   - Запустите снова: `npm start`
   - Или пересоберите проект: `npm run build`

## Примечания:

- Бесплатный план EmailJS позволяет отправлять до 200 писем в месяц
- Все письма будут приходить на адрес **info@fondcosmos.ru**
- В поле "Reply To" будет указан email отправителя, чтобы можно было ответить напрямую

## Проверка работы:

После настройки попробуйте отправить тестовое сообщение через форму на странице "Контакты". Если все настроено правильно, вы получите письмо на info@fondcosmos.ru.
