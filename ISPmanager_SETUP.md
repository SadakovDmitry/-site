# 🔧 Настройка React Router для ISPmanager (REG.RU)

## Проблема
При открытии `https://testprix.ru/news` напрямую показывается ошибка 404.

## Решение для ISPmanager

### Шаг 1: Загрузите файл `.htaccess` на сервер

1. **В ISPmanager откройте "Менеджер файлов"**
2. **Перейдите в папку `/www/testprix.ru/`** (корневая папка сайта)
3. **Загрузите файл `.htaccess`** из папки `build/` вашего проекта

   ⚠️ **Важно:** Файл `.htaccess` начинается с точки (`.htaccess`), поэтому:
   - В некоторых файловых менеджерах он может быть скрыт
   - Убедитесь, что загружаете именно файл с именем `.htaccess` (с точкой в начале)
   - Если файл не виден, используйте опцию "Показать скрытые файлы"

### Шаг 2: Проверьте права доступа

В ISPmanager установите права на файл `.htaccess`:
- **Права:** `644` или `644 [-rw-r--r--]`

### Шаг 3: Включите mod_rewrite в ISPmanager

1. **В ISPmanager перейдите в раздел "Сайты"**
2. **Выберите ваш сайт `testprix.ru`**
3. **Найдите настройки Apache или "Дополнительные настройки"**
4. **Убедитесь, что включен модуль `mod_rewrite`**

   Если модуль не включен:
   - Обратитесь в техподдержку REG.RU
   - Или попросите включить `mod_rewrite` для вашего аккаунта

### Шаг 4: Проверьте настройки Apache

В ISPmanager проверьте, что для вашего сайта разрешены `.htaccess` файлы:

1. **В разделе "Сайты" → выберите `testprix.ru`**
2. **Найдите "Настройки Apache" или "Дополнительные настройки"**
3. **Убедитесь, что установлено:**
   ```
   AllowOverride All
   ```
   или
   ```
   AllowOverride FileInfo
   ```

### Шаг 5: Проверьте структуру файлов

Убедитесь, что в папке `/www/testprix.ru/` есть:
- ✅ `index.html`
- ✅ `.htaccess` (файл с точкой в начале!)
- ✅ `static/` (папка со всеми файлами)
- ✅ `asset-manifest.json`

### Шаг 6: Проверьте работу

1. **Очистите кэш браузера:** `Ctrl+Shift+R` (Windows) или `Cmd+Shift+R` (Mac)
2. **Попробуйте открыть:** `https://testprix.ru/news`
3. **Должна открыться страница новостей, а не ошибка 404**

---

## 🔍 Если не работает

### Проверка 1: Файл `.htaccess` на месте?

В ISPmanager в "Менеджер файлов":
- Убедитесь, что файл `.htaccess` находится в `/www/testprix.ru/`
- Проверьте, что он не называется `htaccess` (без точки) или `.htaccess.txt`

### Проверка 2: Содержимое файла `.htaccess`

Откройте файл `.htaccess` в ISPmanager и убедитесь, что содержимое такое:

```apache
<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /
  RewriteRule ^index\.html$ - [L]
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  RewriteCond %{REQUEST_FILENAME} !-l
  RewriteRule . /index.html [L]
</IfModule>
```

### Проверка 3: Обратитесь в техподдержку REG.RU

Если ничего не помогает, напишите в техподдержку REG.RU:

**Текст запроса:**
```
Здравствуйте! У меня сайт на React (SPA - Single Page Application),
и при прямом открытии URL (например, /news) показывается ошибка 404.

Мне нужно:
1. Включить модуль mod_rewrite для моего аккаунта
2. Разрешить использование .htaccess файлов (AllowOverride All)

Домен: testprix.ru
```

---

## 📝 Альтернативное решение (если mod_rewrite недоступен)

Если в ISPmanager нельзя включить `mod_rewrite`, можно использовать файл `404.html`:

1. **Скопируйте `index.html` в `404.html`** в папке `/www/testprix.ru/`
2. **Это заставит сервер показывать `index.html` при любой ошибке 404**

Но это менее элегантное решение, лучше использовать `.htaccess`.
